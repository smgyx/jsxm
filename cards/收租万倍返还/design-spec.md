## 项目定位

- 项目名称：收租万倍返还【工作名，可改】
- 形式：角色卡（世界书内嵌）+ MVU 变量系统（MagVarUpdate 同栈）
- **发布架构（用户已定）**：卡 B 式薄卡 + 远程客户端——游戏脚本与前端界面放在**用户自己的 GitHub 仓库**，卡内通过加载正则从 jsdelivr 拉取（同卡 B 的 `客户端界面(吞正文)` 模式）；卡内自包含提示词、世界书、MVU 初始化与加载正则。加载失败时卡内给兜底提示。仓库内容全部原创，不引用卡 B 作者的引擎。
- 主题：神豪收租流 × 公寓群像模拟（都市爽文角色扮演）
- 体验目标：数值滚雪球爽感 + 小妹团养成陪伴喜剧 + 打脸装逼即时痛快
- 情感落点：爽感释放为主，轻松治愈与群像陪伴为辅

## 世界观概念

- 现实向现代都市，**直接使用真实地名（用户已定）**。多舞台推进：杭州大别墅 → 杭州扩张 → 临安山村 → 山庄 → 上海（随剧情换地点，见剧情设计）
- **地点方案（用户已定：虚构地名改真实地名）**：主舞台杭州（钱江新城CBD、汽车城、万象城、城站等真实地标），第五幕省城级都市=上海（徐汇西岸、陆家嘴），第三幕乡村=杭州临安山区；翡翠湾别墅区、月牙湾山庄、星耀传媒等**原作设定的机构名保留**，落在真实城市中
- 唯一天外设定：**收租万倍返还系统**【默认名，待确认】。规则底面（自小说提取）：
  - 收租触发随机倍数返利（万倍为高光），劳动所得交租同样触发
  - 消费返利与情绪价值反馈（辅规则，参考《投资返利.txt》开局机制点子）
  - 任务系统：帮租客/完成委托 → 随机倍数奖励 + 隐藏奖励
  - 特殊租金判定：非现金租金（劳务、物品、名表）触发特殊结算
  - 成长线：神豪等级/返现倍数提升；**被动能力全保留（用户已定）**：解锁顺序对照小说（2026-10-04 修正）——龙精虎猛+百毒不侵开场首笔即得，读心术限定版/黄金瞳幕二，商业洞察之眼幕三，黑客精通幕四
  - **被动效果与体现（2026-10-04 补）**：每个技能写明效果+体现方式——龙精虎猛/百毒不侵/黑客精通不播报、写进身体与场面（体力恢复快/酒桌药局免疫反差/情报核查结果）；读心术播【已激活·今日剩余N次】+心声引文；黄金瞳瞥见自动弹价值标签（不耗次数）、深查耗每日3次；商业洞察之眼读人弹风险标签、读企业弹债务明细、合同条款标红。主动技能次数记录在 主角.技能次数（上限3，跨天重置），状态栏被动技能行显示"技能名(N/3)"
- 社会层：传媒娱乐圈同行竞争、地方豪族长线（宋家式认领、李家式对手）、海外线（安娜式钩子）

## 角色方向

- **<user>**：原创角色——**刚买下**翡翠湾大别墅（三层上叠，小说原作同款设定：别墅是买的，不是祖产）的年轻房东，系统宿主。开局状态（用户已定）：**名下仅此一套物业，手头现金只剩几千块**——收租返利是唯一现金流，这是开局的核心压力与动力。自住主楼，楼上房间出租给小妹团（"楼上楼下都是家"），其他产业随剧情添置。职权：收租/免租、收编租客、改造升级。性格由玩家言行塑造，卡不代言。
- **租客班底**（源自小说，二创改编，关系锚点全部从林野改挂到 <user>，人设底色与语言习惯保留）：
  - 苏星彤（领头嘴炮王）、宋小惠（软糯贪吃，身世线钩子）、沈嘉欣（账房/直播运营）、陈小雯 & 陈小薇（双胞胎）
  - **林小鹿（用户已定）**：作为**可选招募租客**登场（人设由林野之妹改编为独立社会人），收不收进别墅由**玩家在剧情中决定**
  - 后期可入：周小萌、赵悦、安娜（国际线钩子，可选）
- **配角与反派**：日常 NPC（保安、小卖部老板、中介、同行经理）+ 动态反派模板（舔狗情敌、黑心同行、图谋不轨富商、诈骗团伙）
- **拟人系统助手（用户已定：暂时去除）**：卡 A"神豪娘"式人格模块不进首版；架构预留扩展位（系统播报通道独立成条目/脚本接口，后期可作为人格模块挂入，不动主体结构）
- 条目写法学卡 B：表面/隐藏特质/破绽规律分层 + 知情范围纪律 + "当前现场事实优先"
- **说话与思维硬约束（2026-10-04 补，依据小说）**：苏星彤/宋小惠/沈嘉欣三人调色盘条目各加固定块——说话方式硬限制（星彤"叔"字诀+短句江湖话术+大嗓门；小惠超短句附和+软糯鼻音+谎话必露馅；嘉欣轻声+补账式纠错+"彤姐你别说了"拦话）、遇事反应链（星彤先算生存再扛风险；小惠先看彤姐脸色；嘉欣先记后算退路）、三人同场分工（星彤主谈/小惠捧哏/嘉欣兜底）、小说原文语录作语气基准
- **称呼严格化（2026-10-04 补，用户已定）**：女主们从初见第一句起一律叫「叔」（星彤叔不离口/小惠叔·林叔/嘉欣正题才带叔；背地里密谋可用「老登」）；双胞胎、周小萌、赵悦同为「叔」，林小鹿是亲妹叫「哥」，女性<user>统一改「姐」；禁止「林老板」「老板」（小说里是村民和反派的叫法）——全局规则入扮演准则
- **台词硬闸（2026-10-04 真机反馈补）**：真机出现「林大老板」+保姆腔翻车句与AI自造"系统经验值"——星彤调色盘升级为禁令清单+正反例对照（反例即真机翻车句，正例给基准味儿），扮演准则加两条常驻自查：女主台词逐句对照调色盘（星彤每句必须19岁街头精神小妹味）、禁止发明设定外机制（经验值/签到/商城/转盘等一律不存在）
- **状态栏片段式重构（2026-10-04 真机排障）**：真机症状=界面 HTML 渲染但脚本不执行（干净浏览器实测脚本正常）——对比能跑的卡B发现：卡B代码块是**片段**（body+script，177字节加载器），我们的是**完整 HTML 文档**包装，用户环境对完整文档块只渲染不执行。已改为片段式（FA link+style+app div+script，**界面仍全内嵌卡内，无 GitHub 依赖**）；卡B式 jsdelivr 远程加载留作后续可选（需用户上传 dist）
- **真机四修（2026-10-04 晚，用户反馈）**：①正文文字版状态栏（【世界】【现金】式面板）——扮演准则加禁令，数值只经 UpdateVariable+界面终端展示；②开局首笔结算补**座驾奖励**（小说第7章路虎揽胜豹子号凭空在手、第12章缺章，用户确认按奖励处理）——5元结算=现金5万+双被动；**路虎揽胜（浙A88888）改为「苏星彤丝袜抵租」的特殊结算奖励**（小说原生：丝袜顶房租→系统给车，独立隐藏事件，不在开场结算里）；③三小妹**当前无工作无证件**——速览加"当前状态限制"：身份证被卢冰雁扣押（索要时只能说明经过，掏不出证件，幕2任务才取回）、无收入来源不安排打工发传单、生活费靠<user>；④幕1事件链同步上述两项

## 互动与动态需求

- **核心循环**：收租/免租/帮租客 → 系统结算播报 → 返利滚雪球 → 再投资（房租减免、产业、送礼、别墅与物业改造）→ 关系与剧情推进
- **追踪变量**（MVU，比卡 A 精简）：户表（租客档案：好感/心理/情绪/欠租状态/个人目标）、user 资产（现金/积分/神豪等级/返现倍数/名下产业）、任务板、日程约定、世界时钟（时段制）、精力体力（轻量）
- **硬性门槛系统（用户已定）**：数值没达标就不能做，系统以【条件未满足】式播报硬拦截，不硬拗剧情。门槛类型：
  1. **阶段推进门槛**：进入下一幕需同时满足（示例，具体数值建卡时定）：累计返利/资产档位 ≥ 幕需求、神豪等级 ≥ 幕需求、在住租客平均好感 ≥ 幕需求、本幕关键事件已完成
  2. **行动门槛**：别墅/物业改造需现金+设施等级前置；收编新租客需空房+好感门槛；特殊剧情需对应租客好感/堕落阈值；被动解锁需等级门槛
  3. **资源门槛**：精力/体力不足时部分行动不可用（参考卡 B 的资源制）
- 反馈节奏：即时短播报 + 短期任务 + 幕级长期目标；知情范围纪律（NPC 不感知系统）
- **任务派发逻辑（2026-10-04 补）**：任务从现实契机里长出（租客新麻烦/幕目标缺口/日程约定），无契机不派发；同时只挂 1 个当前任务+任务板≤3；完成当轮只结算不接续，隔一段剧情或半天看情况再派；相关事项可成任务链（完成一环解锁下一环）
- **任务即剧情推手（2026-10-04 补，用户已定）**：每幕配「系统任务剧本」（写在阶段指导，完成一环推进事件链一环）——幕1 开张大吉/房东的体面/安居起步（攒2万完成设施0→1）；**幕2 开局首任务=拿回身份证（用户已定，小说原生 ch10-13）：骗子KTV头目卢冰雁扣证 → 对质+警方 → 陈小雯供出密码4399 → 日租房取回全部证件，双胞胎作为同批受害者获救收编（五人团成形，随后触发银脚链隐藏结算）**；之后 接手星耀/反黑前线/爆款制造；幕3 老家来信/修路先锋/村霸现行；幕4 山庄开业/安保体系/远方的客人；幕5 竞标准备/宋家底牌/终局一锤。另设**隐藏任务**（小说原生"走哪都能刷到隐藏任务"）：事件链大节点（银脚链抵租/宅基地重建/名表抵租）不预告，剧情走到直接结算额外奖励；卢冰雁已入反派档案（突发事件条目）
- **别墅经营闭环（2026-10-04 补）**：口碑（软件，人情/租客满意/公共事件/自发传播涨，冲突拖延跌）与设施等级（硬件，只靠现金按五档改造阶梯 2万→10万→50万→200万→1000万 提升，工程跨 1~3 轮）双线并行；闭环=返利现金→改造→体验与口碑→好租客上门+租金溢价→现金再投资；系统任务可派发任一环节；口碑≥30 好租客主动上门、幕4→5 需口碑≥60

|---|---|---|---|

| 第三幕·乡土 | 临安山村 | 基建与修路、盖房、地方恶霸、乡土喜剧线 | 第二幕门槛达成 |
| 第四幕·山庄 | 月牙湾山庄（杭州西南山区） | 产业经营（业务线）、国际线人物登场、豪族初触 | 第三幕门槛达成 |

- 缺章声明：第 12/30/35 章缺失，相关事件链以现有文本为准，不补编

## 风格意向

- 视角：第三人称限知（跟随 <user>），穿插系统面板/短播报
- 语言：口语化爽文，对话密集，网络梗与方言味，文学密度轻
- 描写侧重：对话 + 动作 + 播报；节奏紧凑，打脸当场结算
- 情绪基调：爽快 + 温情 + 市井喜剧（擦边）

## 开场构思（2026-10-04 四改：开局严格按小说走 + MVU 登记界面）

- **四拍交代（用户已定）**：大厂离职（被"组织架构调整"体面优化）→ 处了三年的对象提分手 → 全部积蓄全款拿下翡翠湾三层江景叠墅（精装拎包入住，卡里剩 3000）→ 站在江景客厅里情绪波动，**系统当场绑定**（小说原生触发条件，先于首笔租金），系统提示"收租是激活万倍返还的唯一途径"
- **开局节奏（严格按小说，返利=万倍现金+双被动 2026-10-04 定稿）**：因为万倍返还，<user> 在坡道口向三个精神小妹主动开出**"江景别墅，日租 50 一天"**的条件 → 被苏星彤当场嘲讽 → 三人大声密谋（台词照小说）→ 窘迫半信半疑掏出**全部身家 5 块钱**付首日房租 → 触发**全部身家加成：5元×10000倍=50000元现金入账 + 附加奖励双被动龙精虎猛/百毒不侵** → **当天入住**（三人合住二楼东，台词含报家门）→ 系统提示档案缺失，收束到登记界面
- **接手登记走 MVU 终端界面（用户已定）**：状态栏在 主角.已登记=false 时渲染登记表单（姓名/年龄/性别/身高/体型/外貌/衣着），「按林野来·直接开局」或填表「以此档案开局」，提交走正常发送链（/send+/trigger），由 AI 按变量规则覆写主角字段并置 已登记=true；不再用正文文字登记
